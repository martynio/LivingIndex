# Contributing to Living Index

Thank you for your interest. Living Index is currently in the **proposal and data-feasibility phase**; development work has not been authorized by the proposal alone.

## Useful contributions at this stage

- Links to primary statistical sources relevant to Poland or the Netherlands.
- Corrections to definitions of wages, household income, prices, working time, or survey measures.
- Evidence about historical coverage, publication revisions, and licensing/attribution conditions.
- Accessibility and interpretation issues in the proposed product.

Please **open an issue before preparing a substantive pull request**. Describe the problem, source, timeframe, population, unit, and expected interpretation. Research findings are not automatically accepted as production data.

## Standards

- Separate **source observations**, **derived calculations**, **hypotheses**, and **unknowns**.
- Do not silently impute missing years or combine incompatible statistical populations.
- Cite official datasets or clearly identify the authority and limitations of alternative sources.
- Do not upload private household budgets, credentials, paid datasets, or datasets without verified redistribution rights.
- For future code submissions, keep changes focused, explain verification steps, and avoid unrelated refactors.
- Use English for repository-level technical documentation. The planned user interface supports EN/PL/NL.

See [the project proposal](docs/project/LI-PP-001-PROJECT-PROPOSAL-v1.0.md) and [methodology notes](docs/methodology/README.md).

## Licensing status

A public GitHub repository is not automatically open source. Code and data licensing are pending explicit project decisions; do not assume permission to reuse or redistribute the repository or third-party datasets.
