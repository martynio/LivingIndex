## Decision gates

1. **DISCUSS:** capture and assess proposals.
2. **RESEARCH:** establish data coverage, provenance, legal terms and gaps.
3. **DECIDE:** approve a feasible MVP and measurable completion criteria.
4. **REPO CHECK:** inspect the current branch, commits, files and tests before implementation.
5. **EXECUTE:** work only on authorized scope.
6. **VERIFY:** inspect evidence and regressions, not just reports.
7. **COMMIT / RELEASE GATE:** checkpoint and explicit approval before release.

No development milestone, dataset coverage, or launch date is represented as complete by this scaffold.
