# Decision records

This directory will hold short, durable Architecture Decision Records (ADRs) and scoped product decisions **after operator approval**.

Suggested record fields: identifier, date, status, context, alternatives, decision, consequences, superseded-by (if relevant).

No architectural decisions beyond the accepted initial product direction are invented here. The proposed stack and boundaries are documented in [LI-PP-001](../project/LI-PP-001-PROJECT-PROPOSAL-v1.0.md).
