# Localization

LI-003A contains eight static routes in each of EN, PL and NL. English is the root default; `../pl/` and `../nl/` contain corresponding localized HTML. There is no translation loader, language persistence or runtime JavaScript. Keep route filenames, hreflang, document lang, navigation labels, equivalent locale links, headings and draft markers synchronized. Translate statistical meaning faithfully when a later scope introduces data.

See [web preview and editing instructions](../README.md). The legal placeholders are not approved translations of legal policies.
