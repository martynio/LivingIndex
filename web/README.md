# Web interface

**Status: reserved for future implementation; no functioning website is included yet.**

Proposed lightweight static frontend: semantic HTML, Bootstrap 5+, Pinegrow-compatible markup, JavaScript and Chart.js. The interface must remain responsive, keyboard-accessible, and truthful about incomplete data.

Planned structure:

```text
web/
├── index.html           # Future entry point, not implemented
├── assets/
│   ├── css/             # Styles
│   ├── js/              # UI and data presentation
│   └── images/          # Project-owned visual assets
└── i18n/                # UI strings: EN / PL / NL
```

The actual interface, data access contract, visualization design and translation catalogs will be created **only after research and scope approval**. There is no simulated production data here.
