PODGLĄD ROZWOJOWY — POLITYKA W WERYFIKACJI

Informacje dotyczą aktualnego podglądu rozwojowego. Nie stanowią kompletnej ani zatwierdzonej informacji prawnej. Ostateczny dokument zostanie sprawdzony przed wydaniem produkcyjnym.

Hosting i bezpieczeństwo

Podgląd jest udostępniany przez GitHub Pages. GitHub zapisuje adresy IP odwiedzających w celach bezpieczeństwa, również podczas wizyt bez konta GitHub. Zobacz informacje o zbieraniu danych w GitHub Pages i politykę prywatności GitHub.

Funkcje projektu

Aktualny kod projektu nie zawiera kont, formularzy kontaktowych, skryptów analitycznych ani reklamowych mechanizmów śledzenia. Dashboard przetwarza hipotetyczne kwoty lokalnie; nie podawaj prywatnego budżetu. Kod projektu nie przesyła ani nie zapisuje tych wartości. Przetwarzanie po stronie hostingu jest odrębną kwestią.

Informacje w trakcie weryfikacji

Dane administratora projektu, prywatny kanał realizacji praw, właściwe podstawy prawne, retencja i zasady transferu wymagają potwierdzenia. Nie przesyłaj danych osobowych ani informacji poufnych w publicznych dyskusjach repozytorium.
