ONTWIKKELVERSIE — BELEID IN BEOORDELING

Deze informatie beschrijft de huidige ontwikkelversie. Het is geen volledige of goedgekeurde juridische verklaring. Het definitieve beleid wordt vóór een productierelease beoordeeld.

Hosting en beveiliging

Deze ontwikkelversie wordt gehost via GitHub Pages. GitHub registreert IP-adressen van bezoekers voor beveiliging, ook bij bezoeken zonder GitHub-account. Zie gegevensverzameling bij GitHub Pages en de privacyverklaring van GitHub.

Projectfuncties

De huidige projectcode bevat geen accounts, contactformulieren, analysescripts of advertentietrackers. Het dashboard verwerkt hypothetische bedragen lokaal; voer geen persoonlijke budgetten in. De projectcode verzendt of bewaart deze waarden niet. Verwerking door de hostingdienst staat los van deze projectfuncties.

Informatie in beoordeling

De gegevens van de verwerkingsverantwoordelijke, een privécontactkanaal voor privacyverzoeken, toepasselijke rechtsgronden, bewaartermijnen en doorgifteregelingen moeten nog worden bevestigd. Deel geen persoonsgegevens of vertrouwelijke informatie in openbare discussies van de repository.
