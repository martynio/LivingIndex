# Data workspace

**There are no approved statistical datasets in this repository yet.**

- [`raw/`](raw/): approved, provenance-tracked source snapshots (only if redistribution rights permit).
- [`curated/`](curated/): validated, versioned, reproducible transformations intended for the interface.

Before accepting data: document the original source, dataset ID, retrieval timestamp, publication/revision date, period, population, unit, methodology, transformations, license/attribution, and verification outcome.

Do not commit personal information, API keys, private budgets, restricted data, or fabricated numerical series. The schema and ingestion process remain subject to the data-feasibility gate.
